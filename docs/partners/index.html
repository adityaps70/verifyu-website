How partner offers
are designed to work.

    Create an offer

    A discount, a bundle, a trial or a service — you decide.

    Set the Coin requirement

    How many VerifyU Coins a user puts towards it.

    Reach VerifyU users

    Eligible offers can be shown inside the rewards experience.

  4. 04

    Visits & redemptions

    Users unlock the offer and walk in.

  5. 05

    Measure

    Visits, redemptions and repeat use — agreed before, not after.
